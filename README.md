# 🧮 Simple Calculator – React Basics Project

## 📌 Project Overview

This project is a **Simple Calculator** built with **React** to strengthen core React fundamentals.
The application allows users to perform basic arithmetic operations between two numbers and view the result instantly.

## ✨ Features

* Input two numbers
* Perform basic arithmetic operations:

  * ➕ Addition
  * ➖ Subtraction
  * ✖️ Multiplication
  * ➗ Division
* Display calculation results in real time
* Simple and beginner-friendly UI

## 🛠️ Technologies Used

* **React**
* **JavaScript (ES6)**
* **CSS** 

## ⚙️ How It Works

* Two input fields allow users to enter numbers.
* Buttons trigger different arithmetic operations.
* **useState** stores:

  * Input values
  * The calculation result
* The result updates dynamically when an operation is performed.

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rianspies/Calculator
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the application

```bash
npm run dev
```

The app will open at `http://localhost:5173`.

## 🧠 Example Operations

```js
Addition:        a + b
Subtraction:     a - b
Multiplication: a * b
Division:        a / b
```
